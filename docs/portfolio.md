# Portfolio copy

I built Manuscript to Handoff with AI assistance to make one part of my publishing workflow easier to trust: getting approved text into production without losing or changing it. It's a public Python application with editorial suggestions, human review, revision-specific approval, and deterministic checks of the actual handoff package. The demo introduces missing text and an earlier revision so you can see export stop, inspect the failure, and recover. I supplied the product brief and workflow requirements; AI assisted with the implementation. The repository includes automated tests, CI, a real-browser verification record, and a reproducible demonstration. It's a bounded portfolio prototype, with no claimed customers or measured business results.

**Resume bullet**

- Built an AI-assisted publishing workflow prototype using Python, Streamlit, and SQLite, with revision-bound human approval and deterministic validation of manuscript text and exported handoff packages.
